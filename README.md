## 🌟 About the Project

This portfolio showcases the academic journey, technical toolkit, interests, and goals of **Ansha Ponde**, a first-year Computer Science and Engineering (AI & ML) student at **Newton School of Technology**.

Designed with an **Awwwards-level futuristic aesthetic**, it demonstrates advanced frontend styling using **only pure CSS3**—no JavaScript, no animation frameworks, and no external UI component libraries.

## 🚀 Key Visual & Interactive Features

- **Abstract 3D CSS Hero Composition:** Multi-axial floating concentric orbital rings, glowing electric blue sphere core with radial light diffusion, and rotating 3D isometric glass cubes.
- **Glassmorphism UI:** Backdrop filters, multi-layered depth, glowing borders, and subtle perspective tilts.
- **Pure CSS Mobile Navigation:** Accessible checkbox-driven slide-out navigation menu for seamless mobile viewing.
- **Futuristic Vertical Timeline:** Glowing pulse nodes and an animated traveling light beam highlighting higher education.
- **Pure CSS 3D Illustrations:**
  - *Reading:* 3D floating book model with stacked pages and bookmark ribbon.
  - *Music:* 8-bar soundwave equalizer with pulsating heights and floating musical notes.
  - *Table Tennis:* Perspective court grid, rubber paddle, and dynamic bouncing ball animation.
- **Interactive Terminal Mockup:** Retro-futuristic development workbench empty state for upcoming projects.
- **Personality Bento-Grid:** Editorial multi-card layout with rotating CSS compass art.
- **Accessibility:** Full support for `prefers-reduced-motion` to ensure comfortable viewing for all users.
